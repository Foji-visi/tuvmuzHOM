# Ырылар — угадай тувинскую песню

Игра в духе songless.ru: угадай тувинскую песню по отрывкам 0,5 → 1 → 2 → 4 → 8 → 15 секунд.

## Режимы

- **Песня дня** — 5 песен, одинаковые у всех; новые каждый день в 00:00 (по UTC+7). Сыграть можно один раз в сутки.
- **Соло → Рандом** — 5 случайных песен от разных исполнителей, без ограничений.
- **Соло → Артисты** — каталог исполнителей (собирается сам из `songs.json`); у артиста — 10 случайных его песен.
- **Дуо** — игра против друга по ссылке на комнату. Пока «скоро»: нужна серверная часть.
Звук берётся с YouTube (встроенный плеер) или из своих mp3-отрывков в папке `clips/`. Сайт работает на GitHub Pages.

## Файлы

| Файл | Что внутри |
|---|---|
| `index.html` | разметка страницы |
| `style.css` | оформление |
| `app.js` | вся логика игры и плеер YouTube |
| `songs.json` | **список песен для всех игроков** |
| `clips/` | mp3-отрывки по 20 секунд (появится, когда добавишь первый) |
| `lame.min.js` | кодировщик mp3 — нужен режиму автора, чтобы вырезать отрывки |
| `artists.json` | (необязательно) фото артистов: `{"Enamor": "artists/enamor.jpg"}` |
| `artists/` | (необязательно) картинки артистов, лучше квадратные |

## Как включить сайт (один раз)

1. Репозиторий должен быть **Public**.
2. **Settings → Pages → Build and deployment**.
3. Source: **Deploy from a branch**, Branch: **main**, папка **/ (root)** → **Save**.
4. Через 1–2 минуты сайт откроется по ссылке `https://ТВОЙ-НИК.github.io/tuvmuzHOM/`.

## Как добавить песню

Открой сайт с `#admin` в конце адреса: `https://ТВОЙ-НИК.github.io/tuvmuzHOM/#admin` → «Песни».

**Ссылкой YouTube:** вкладка «Ссылка YouTube» → ссылка, исполнитель, название → «Добавить».
Много сразу: «Добавить много песен сразу», формат строки `ссылка ; исполнитель ; название ; начало`.

**Файлом mp3** (из ВК, Telegram и т.п.):
1. Вкладка «Файл mp3» → выбери файл. Если он назван «Исполнитель - Название.mp3», поля заполнятся сами.
2. Укажи, с какого места вырезать (по умолчанию с начала), проверь кнопкой ▶ → «Добавить».
3. Сайт вырежет 20 секунд и скачает маленький файл (~300 КБ).
4. Загрузи его в папку `clips` на GitHub (кнопка «Открыть на GitHub» → перетащи файл → **Commit changes**).

**Потом в любом случае — сохранить список для всех:**
1. Внизу «Сохранить для всех игроков» → «Скопировать» → «Открыть songs.json на GitHub».
2. Выдели всё в файле → вставь → **Commit changes**.
3. Через 1–2 минуты сайт обновится у всех.

Можно править `songs.json` и вручную, одна песня на строку:

```json
[
  {"yt":"wAdZLKWIljA","artist":"Enamor","title":"Таныжып алам","start":0},
  {"file":"clips/ispolnitel-nazvanie.mp3","artist":"Исполнитель","title":"Название"}
]
```

- `yt` — 11 символов из ссылки: `youtu.be/`**`wAdZLKWIljA`**
- `start` — с какой секунды начинать (если в начале клипа заставка)
- `file` — путь к отрывку в папке `clips`
- между песнями запятая, после последней — **без** запятой

## Настройки игры

В начале `app.js`:

```js
const STEPS = [0.5, 1, 2, 4, 8, 15];            // длина отрывков
const POINTS = [1000, 850, 700, 550, 400, 250]; // очки за 1-ю…6-ю попытку
const ROUND_SIZE = 5;                       // песен в «Песне дня» и «Рандоме»
const ARTIST_ROUND = 10;                    // песен в режиме «Артист»
```

## Важно

Сайт работает только по ссылке GitHub Pages. Двойной клик по `index.html` не подойдёт:
YouTube не играет видео на страницах, открытых как файл, а `songs.json` не загрузится.
