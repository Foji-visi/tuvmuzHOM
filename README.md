# Ырлар — угадай тувинскую песню

Игра в духе songless.ru: 5 случайных тувинских песен, отрывки 0,5 → 1 → 2 → 4 → 8 секунд.
Звук берётся с YouTube через встроенный плеер. Сайт работает на GitHub Pages.

## Файлы

| Файл | Что внутри |
|---|---|
| `index.html` | разметка страницы |
| `style.css` | оформление |
| `app.js` | вся логика игры и плеер YouTube |
| `songs.json` | **список песен для всех игроков** |

## Как включить сайт (один раз)

1. Репозиторий должен быть **Public**.
2. **Settings → Pages → Build and deployment**.
3. Source: **Deploy from a branch**, Branch: **main**, папка **/ (root)** → **Save**.
4. Через 1–2 минуты сайт откроется по ссылке `https://ТВОЙ-НИК.github.io/irlar/`.

## Как добавить песню

1. Открой сайт с `#admin` в конце адреса: `https://ТВОЙ-НИК.github.io/irlar/#admin`.
2. Нажми «Песни», вставь ссылку YouTube, впиши исполнителя и название, нажми «Добавить».
   Можно добавить сразу много: «Добавить много песен сразу», формат строки
   `ссылка ; исполнитель ; название ; начало`.
3. Внизу открой «Сохранить для всех игроков» → «Скопировать» → «Открыть songs.json на GitHub».
4. Выдели всё в файле → вставь → **Commit changes**.
5. Через 1–2 минуты сайт обновится у всех.

Можно править `songs.json` и вручную, одна песня на строку:

```json
[
  {"yt":"wAdZLKWIljA","artist":"Enamor","title":"Таныжып алам","start":0},
  {"yt":"ID_ВИДЕО","artist":"Исполнитель","title":"Название","start":0}
]
```

- `yt` — 11 символов из ссылки: `youtu.be/`**`wAdZLKWIljA`**
- `start` — с какой секунды начинать (если в начале клипа заставка)
- между песнями запятая, после последней — **без** запятой

## Настройки игры

В начале `app.js`:

```js
const STEPS = [0.5, 1, 2, 4, 8];          // длина отрывков
const POINTS = [1000, 800, 600, 400, 200]; // очки за 1-ю…5-ю попытку
const ROUND_SIZE = 5;                       // песен за игру
```

## Важно

Сайт работает только по ссылке GitHub Pages. Двойной клик по `index.html` не подойдёт:
YouTube не играет видео на страницах, открытых как файл, а `songs.json` не загрузится.
