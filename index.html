Отрывок готов (). Осталось загрузить его на GitHub:
  1. Скачай файл (обычно скачивается сам): ⬇ Скачать
  2. Открой папку clips в репозитории: Открыть на GitHub ↗
  3. Перетащи туда скачанный файл → Commit changes.

Сохранить для всех игроков

Песни, добавленные здесь, видишь только ты. Чтобы они появились у всех:

  1. Нажми «Скопировать».
  2. Открой файл songs.json в своём репозитории на GitHub (кнопка ниже) и нажми карандаш ✎ (Edit), если редактор не открылся сам.
  3. Выдели всё старое (Ctrl+A), вставь скопированное (Ctrl+V).
  4. Нажми Commit changes. Через 1–2 минуты сайт обновится сам.
